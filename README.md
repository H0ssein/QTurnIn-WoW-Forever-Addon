# QTurnIn

QTurnIn is a lightweight and efficient quest automation addon designed to speed up your leveling and daily routines.

## Features

- **Auto-Questing**: Automatically accepts and turns in quests when interacting with NPCs, bypassing repetitive dialogue. *(Note: You can hold the **Shift** key while talking to an NPC to temporarily pause the automation).*
- **Nameplate Objective Marks**: Places clear indicators directly above enemy nameplates (e.g., Skulls for kill objectives, Loot bags for item collection) so you instantly know which mobs you need for your active quests.

## Slash Commands

Use `/qt` or `/qturnin` to easily toggle features on or off. All settings are saved across your play sessions.

- `/qt auto` : Toggles the Auto Quest Accept/Turn-in feature.
- `/qt mark` : Toggles the Nameplate Objective Marks.
- `/qt party` : Toggles showing Quest Objectives for Party Members on nameplates.
